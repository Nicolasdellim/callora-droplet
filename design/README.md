# Callora identity

Original vector artwork, generated by `scripts/render-artwork.swift`; editable master in `master.svg`. No generated imagery or third-party marks.

Three concepts: 1. Island and floating screen, 2. Overlapping surfaces, 3. Framed video camera. Selected concept 1 emphasizes detachment rather than another calling app. Small-size review should inspect `callora-16.png`, `callora-32.png`, and the contact sheet: the top capsule and large empty screen survive reduction; concept 2 merges, and concept 3 reads as a generic camera.

`Callora.icon` is a real Icon Composer directory, with JSON and referenced transparent PNG layers. It is custom development/GitHub artwork, supplied because the product brief explicitly requests it. Droppy's current Store policy reserves final Store icons for its maintainer. Do not send this icon as an approved Store icon. The Store staging command excludes it; propose the capsule-to-floating-screen idea in the merge request instead.

`store-preview.png` is an icon artwork preview, not an approved Store listing. `social-preview.png` is promotional artwork, not a product screenshot. Screenshots under `docs/screenshots/` come from the real SDK harness and are labeled by state.
